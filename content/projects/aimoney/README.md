# AI 变现项目模板包

本文件夹包含三个可直接使用的模板：

| 文件 | 用途 |
| --- | --- |
| `prompt-library.json` | 个人提示词库模板，含 8 条经过打磨的提示词，可直接复制使用 |
| `workflow-design.md` | 搭建自动化工作流前的设计表，重点是分清「哪些必须人工把关」 |
| `README.md` | 本说明文件 |

## 怎么用

1. 先用 `prompt-library.json` 里的提示词跑通你自己的高频场景，把 `{{变量}}` 换成你的内容。
2. 观察哪些提示词输出不稳定，按「角色 + 任务 + 上下文 + 约束 + 输出格式」的结构补齐缺失的部分。
3. 当某个提示词被反复使用时，它就是你产品的原型 —— 进入 `workflow-design.md` 把它设计成工作流。
4. 把 `lastScore` 字段当成筛选器：低于 4 分的提示词要么修好，要么删掉，不要留在库里。

## 提示词写不好的三个典型症状

- **输出格式不稳定** → 缺「输出格式」约束，或没给示例（Few-shot）
- **内容爱编造** → 缺「找不到就填 null / 不要编造」这类负向约束
- **每次都太长** → 缺字数上限，模型默认往长了写

## 需要特别注意

- 提示词里凡是涉及具体人名、公司名、认证名称、数据的，一律用 `{{变量}}` 或 `[待核实]`，不要让模型自由发挥。
- 涉及客户信息的提示词，注意数据合规；不要把客户的商业机密发给第三方模型。
