# AI 自动化工作流设计表

> 用法：在搭建任何工作流之前，先用这张表把一个场景拆清楚。
> 目的很简单：**分清哪些环节该交给 AI，哪些环节必须由人把关。**

---

## 步骤 0：场景描述

| 项目 | 内容 |
| --- | --- |
| 场景名称 | [例：外贸开发信批量生成与跟进] |
| 现在怎么做 | [手动查客户资料 → 逐封写邮件 → 记录跟进时间] |
| 单次耗时 | [约 25 分钟 / 每封] |
| 每周频次 | [约 40 封] |
| 痛点 | [重复劳动多、质量不稳定、容易漏跟进] |
| 期望结果 | [单封降到 5 分钟，回复率不低于现在] |

## 步骤 1：环节拆解

| # | 环节 | 人工 / AI | 输入 | 输出 | 是否必须人工确认 | 理由 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | 收集客户信息 | 人工 + 检索 | 公司名 | 结构化客户档案 | 否 | 公开信息，可自动整理 |
| 2 | 判断是否值得跟进 | AI 初筛 + 人工确认 | 客户档案 | 优先级标签 | **是** | 误判会浪费大量时间 |
| 3 | 生成开发信初稿 | AI | 客户档案 + 产品信息 | 邮件草稿 | **是** | 发出去就是不可撤销的对外沟通 |
| 4 | 邮件语法与合规检查 | AI | 草稿 | 修改建议 | 否 | 机器更细心 |
| 5 | 发送 | 人工 | 成稿 | 已发送 | **是** | 账号安全与发送节奏需人工控制 |
| 6 | 记录跟进时间 | 自动化 | 发送记录 | 日历提醒 | 否 | 纯机械任务 |

**规律：只要输出会直接触达外部（客户、用户、公众），就必须设人工确认节点。**

## 步骤 3：质量与成本

| 指标 | 目标值 | 实测值 | 是否达标 |
| --- | --- | --- | --- |
| 单次耗时 | [< 5 分钟] | | |
| 单次成本 | [< 0.5 元] | | |
| 首次通过率（无需返工） | [> 70%] | | |
| 错误率（需人工纠正） | [< 10%] | | |

**评测集：** 准备 10 个真实输入，每次改提示词后重跑一遍，记录通过率。没有评测集就没有优化方向。

---

## 步骤 4：风险检查

- [ ] 输出会不会触达外部？→ 必须有人工确认节点
- [ ] 会不会向模型发送客户隐私数据？→ 需要脱敏或本地部署
- [ ] 会不会因为模型涨价 / 限流导致业务中断？→ 准备备用模型
- [ ] 自动化操作平台是否违反平台服务条款？→ 优先用官方 API
- [ ] 生成内容是否涉及版权或事实错误？→ 建立核查清单
- [ ] 有没有错误告警机制？失败时我多久能发现？
