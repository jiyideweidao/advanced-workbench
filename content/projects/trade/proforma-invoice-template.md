## 使用前自查

- [ ] 总价大写金额与小写金额一致
- [ ] 收款银行信息与你的实际账户一致（错一位就收不到钱）
- [ ] 品名描述与报关用的一致
- [ ] HS Code 已核对过（外贸综合服务平台或报关行可确认）
- [ ] 贸易术语与费用承担条款匹配
- [ ] 客户公司名与其营业执照完全一致（影响清关）
