# 项目一：响应式个人介绍页

这是「网站制作」领域的入门项目模板。目标：用一个页面证明你掌握了 HTML 语义化、Flex/Grid 布局与移动端适配。

## 怎么用

1. 双击 `index.html` 直接在浏览器打开，先看看当前效果。
2. 把 `index.html` 里的「你的名字」「你好，我是一名前端开发者」等占位文字换成你自己的内容。
3. 打开 `styles.css`，修改 `:root` 里的颜色变量，换成你喜欢的配色。
4. 打开 `app.js`，修改 `WORKS` 数组，换成你自己的作品。
5. 用浏览器开发者工具的设备模拟器，分别在 375px / 768px / 1440px 三个宽度下检查。

## 验收标准

- [ ] 手机端不出现横向滚动条
- [ ] 导航在窄屏下不换行错位
- [ ] 所有图片有 `alt` 属性（现在是文字卡片，可先跳过）
- [ ] Lighthouse 性能与可访问性均 ≥ 90 分

## 进阶挑战

- 把 `WORKS` 数组换成从公开 API 请求数据，并处理加载中 / 请求失败两种状态。
- 加入暗色 / 亮色主题切换，并用 `localStorage` 记住用户选择。
- 部署到 GitHub Pages 或 Vercel，拿到一个可以分享的网址。
